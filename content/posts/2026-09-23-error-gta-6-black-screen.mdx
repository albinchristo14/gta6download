## Sound without a picture has to come from something

The description is familiar to anyone who has chased this symptom: audio starts, the display goes dark, the fan note changes, and the game never arrives. It is a convincing story, which is exactly why the first question has to be whether a game is involved at all. GTA 6 has no PC version and none has been announced; the release on 19 November 2026 is on PlayStation 5 and Xbox Series X and Series S. Nothing on your desktop can be a copy of it, so a black screen attributed to it belongs to another program, and if that program arrived as a GTA 6 download then it deserves a security response rather than a display response.

## What the darkness usually is

A black screen with running audio is normally a presentation problem, not a content problem. Fullscreen mode changes force a resolution and refresh-rate renegotiation with the monitor, and a panel that refuses the mode keeps the signal while showing nothing. A graphics driver that times out gets reset by Windows, which can strand an application holding a device that no longer exists. The output can be wrong in an ordinary way, with the picture going to a second display or a capture path instead of the panel in front of you. Power settings will happily drop an idle GPU and its attached display pipeline mid-handshake. On consoles the equivalent list is short: an HDR or refresh negotiation with the television, and a pending update.

## Try these in order of cost

1. Switch the display path first: the monitor input, the cable, and whether a second output is set as the main display. This solves a surprising share of cases and costs nothing.
2. Set Windows to a mode you know the panel accepts, then let the application run windowed so no fullscreen renegotiation is required at all.
3. Reset the graphics driver with the keyboard shortcut for that, then reboot properly rather than using fast startup, which preserves the state you are trying to clear.
4. Turn off variable refresh rate, HDR and any monitor-side overdrive while testing, one change at a time.
5. Restore the power plan so the GPU is not allowed to sleep during startup work.
6. Reinstall the driver with the vendor's own installer, from a clean boot, without touching beta branches.
