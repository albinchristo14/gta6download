## You typed it correctly and the store still said no

Redemption is a storefront transaction, which surprises people who bought a box. The code does not unlock the game; it creates a purchase record on whichever account and whichever store region completes the entry, and that record is what the console then treats as ownership. Every failure mode below follows from that one fact.

It also means the present tense matters. Until 19 November 2026 there is no GTA 6 copy for any code to unlock, so a key emailed to you now, a "physical edition code" sold outside a shop, or a printable voucher promising immediate access is not early access. It is either worthless or bait, and the security research around fake GTA 6 files this year is unambiguous about which is more common.

## Why real codes get refused

- **Wrong storefront.** A PlayStation key cannot be entered on Xbox and the reverse is also true, yet listings on general marketplaces routinely mix them in the same photo.
- **Region lock.** Codes are printed for a territory. A card bought for one region will be rejected in another, and the packaging usually states which.
- **Already spent.** Codes are single use. A previous owner, or a seller working from a photograph of the card, can consume it before you do.
- **Transcription.** Characters that look identical in that typeface cause most avoidable retries, so read the code back character by character rather than retyping it.
- **Withdrawn promotion.** Bundled and time-limited keys occasionally stop working at a cutoff set by whoever issued them.

## Buying second-hand without buying a problem

Sealed is not the same as unopened, and unopened is not the same as unredeemed. Photographs of a scratch-off panel in a listing are an open invitation for a seller to redeem the key themselves and ship the card afterwards, which is why a code in a photograph is not a code you own. If you want a documented chain of entitlement instead of a card, a direct digital purchase is the [legitimate route](/news/where-to-buy-gta-6-legitimately).

## What the disc itself gets you

A physical copy runs from the disc and still needs the launch-day data, since a disc cannot hold a game and its first patch at the same time; the console installs what it has and downloads the rest. If an in-box code accompanies the disc, treat the disc as the entitlement and the code as a separate, expiring extra.
